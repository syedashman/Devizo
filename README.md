# Devizo

Devizo is a modern digital agency website built to showcase services like web development, AI automation, e-commerce solutions, and custom software.

## Overview

- **Platform**: Static HTML/CSS website
- **Features**: animated hero section, service cards, custom cursor, and responsive layout
- **Logo**: Uses `logo/devizo-logo.png` for the brand identity

## Usage

1. Open `devizo.html` in your browser to view the site.
2. Edit `devizo.html` directly to update content, branding, or layout.
3. Place additional assets inside the `logo/` folder as needed.

## GitHub

This repository is configured with a local Git history and is pushed to GitHub at `https://github.com/syedashman/Devizo`.

## Notes

- No build tools are required.
- The site is ready to be deployed using GitHub Pages or any static hosting service.

## GitHub Pages

To publish this site with GitHub Pages:

1. Go to the repository settings on GitHub.
2. Under "Pages", select the `main` branch and `/ (root)` folder.
3. Save the settings.
4. Your site should be available at `https://syedashman.github.io/Devizo/` after a few minutes.
